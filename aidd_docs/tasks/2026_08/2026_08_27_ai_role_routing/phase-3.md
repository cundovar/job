# Phase 3: Tests et documentation

1. Couvrir la propagation modèle/effort et les validations du bridge.
2. Couvrir chaque route et au moins un repli automatique.

## Acceptation

- Les routes sont testées sans appel réel aux fournisseurs.
- Les erreurs de fournisseur n’empêchent pas le secours suivant.
- La documentation permet de changer un modèle sans modifier le code.
